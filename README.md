# HackTools Bot (Gemini AI)

AI কোডিং অ্যাসিস্ট্যান্ট (Google Gemini) + বিল্ট-ইন হ্যাকিং টুলস।

## ফিচার
- /write /review – Gemini AI দিয়ে কোড তৈরি ও রিভিউ
- পোর্ট স্ক্যানার, WHOIS, DNS, IP তথ্য, হ্যাশ, এনকোড/ডিকোড, রিভার্স শেল পেলোড
- সম্পূর্ণ শিক্ষামূলক ব্যবহারের জন্য

## হোস্টিং
1. .env ফাইলে TELEGRAM_BOT_TOKEN ও GEMINI_API_KEY বসাও
2. Railway / Render / VPS-এ ডিপ্লয় করো
3. pip install -r requirements.txt

## Gemini API Key
https://aistudio.google.com/apikey থেকে বিনামূল্যে নিতে পারো।
